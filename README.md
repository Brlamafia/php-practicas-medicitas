# Prácticas PHP — MediCitas

Este repositorio contiene dos prácticas:

- `practica1`: migración de una plantilla HTML a páginas PHP con enlaces internos corregidos.
- `app-medica`: panel administrativo de citas médicas, preparado para servidor local y despliegue remoto.

## Ejecución local

Copiar ambas carpetas a `C:\laragon\www`, iniciar Laragon y visitar:

- `http://localhost/practica1/index.php`
- `http://localhost/app-medica/index.php`

Todas las rutas del proyecto son relativas y los enlaces internos utilizan la extensión `.php`.
